EDA Project - Titanic Dataset

Project Name:
Exploratory Data Analysis (EDA) on Titanic Dataset

Tools Used:

- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

Project Files:

- eda.py
- titanic.csv
- report.docx
- images folder

Description:
This project performs Exploratory Data Analysis on the Titanic dataset. Statistical summaries, visualizations, and correlation analysis were used to identify patterns and insights related to passenger survival.
